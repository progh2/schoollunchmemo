| 항목 | 내용 |
| --- | --- |
| 문서 버전 | 0.1 (초안) |
| 작성일 | 2026-07-29 |
| 제품명 | 학교쪽지 / SchoolNote |

## 1. 개요

### 1.1 한 줄 정의

> **오늘 우리 학교의 급식 메뉴와 학사일정을, 누군가 책상에 슬쩍 붙여둔 포스트잇처럼 보여주는 데스크톱 위젯.**

### 1.2 배경

학부모와 학생, 교직원은 "오늘 급식 뭐지?", "오늘 무슨 행사 있지?"를 확인하기 위해
학교 홈페이지나 별도 앱을 열어야 한다. 확인에 드는 비용(앱 실행 → 로그인 → 탐색)이
정보의 가치보다 크기 때문에, 결국 대부분 확인하지 않고 지나간다.

NEIS 개방포털은 전국 초·중·고의 급식 식단과 학사일정을 무료 Open API로 제공한다.
이 데이터를 **가져와서 보여주는 행위 자체를 없애는 것**이 이 제품의 핵심 가치다.
사용자는 아무것도 하지 않고, 정보가 이미 화면 한구석에 붙어 있다.

### 1.3 제품 원칙

1. **읽기 전용, 무조작.** 사용자가 매일 클릭할 일이 없어야 한다. 켜두면 알아서 갱신된다.
2. **한 화면에 오늘치만.** 주간 캘린더도, 월간 뷰도 아니다. 포스트잇에 적을 만큼만 적는다.
3. **조용함.** 팝업, 알림음, 포커스 뺏기 없음. 배경에 머무르되 언제든 눈에 들어온다.
4. **설정은 처음 한 번.** 인증키 등록과 학교 선택 이후에는 설정 창을 다시 열 일이 없어야 한다.

### 1.4 비목표 (Non-goals)

명시적으로 **하지 않는 것**:

- 급식 사진, 리뷰, 평점 등 커뮤니티 기능
- 시간표, 성적, 출결 등 개인화된 학사 정보 (NEIS 개방 API 범위 밖)
- 모바일 앱 (본 프로젝트는 데스크톱 전용)
- 여러 학교 동시 표시 (v1.1 이후 검토)
- 서버/백엔드 구축 — 앱이 NEIS API를 직접 호출하는 클라이언트-온리 구조

## 2. 사용자

### 2.1 주 사용자

| 페르소나 | 상황 | 원하는 것 |
| --- | --- | --- |
| **초등학생 학부모** | 재택근무 중 PC 앞에 있음 | 아이 급식 메뉴 확인, 단축수업·휴업일 미리 알기 |
| **중·고등학생 본인** | 과제하며 PC 사용 | 오늘 점심/석식 메뉴, 시험·행사 일정 |
| **교직원** | 업무용 PC 상시 사용 | 오늘 학사일정 리마인드 |

### 2.2 대표 시나리오

**S-1. 첫 실행 (온보딩)**
1. 앱을 처음 실행하면 포스트잇에 "설정이 필요해요"가 적혀 있고, 설정 창이 자동으로 뜬다.
2. 설정 창 1단계에서 NEIS 인증키 발급 안내를 읽고, 발급받은 키를 붙여넣는다.
3. **[키 확인]** 버튼을 눌러 유효성을 검증한다. 초록 체크가 뜬다.
4. 2단계에서 학교 이름 일부(예: "미림")를 입력하고 검색한다.
5. 결과 목록에서 우리 학교를 고른다.
6. 저장하면 포스트잇에 오늘 급식과 일정이 즉시 채워진다.

**S-2. 일상 사용**
1. PC를 켜면 앱이 자동 시작되고, 포스트잇이 바탕화면 우측 상단에 붙는다.
2. 사용자는 아무 조작 없이 지나가며 읽는다.
3. 작업에 방해되면 포스트잇을 클릭해 숨긴다 → 트레이 아이콘만 남는다.
4. 나중에 트레이 아이콘을 클릭하면 다시 나타난다.

**S-3. 자정 넘김**
1. 자정이 지나면 앱이 스스로 "오늘"을 갱신해 새 급식/일정을 가져온다.
2. 사용자가 다음 날 아침에 봤을 때 이미 그날 내용이 붙어 있다.

## 3. 화면 명세

### 3.1 포스트잇 위젯 (메인)

프레임리스·항상 위(옵션)·드래그 이동 가능한 반투명 창.

```
 ┌─────────────────────────────┐
 │                          ✕  │  ← hover 시에만 노출
 │  7월 29일 (수)              │
 │  ─────────────────────      │
 │  🍚 중식                     │
 │   기장밥                     │
 │   쇠고기미역국               │
 │   돈육김치찜                 │
 │   콩나물무침                 │
 │   배추김치                   │
 │   요구르트                   │
 │                    678 kcal │
 │                              │
 │  📌 오늘 일정                │
 │   여름방학식                 │
 │   1·2·3학년                  │
 │                              │
 │           09:12 갱신됨       │
 └─────────────────────────────┘
```

**요구사항**

| ID | 내용 |
| --- | --- |
| W-01 | 프레임리스(제목표시줄 없음), 모서리 라운드, 종이 질감의 배경색 |
| W-02 | 창 어디든 드래그해 이동 가능. 위치는 설정에 저장되어 재시작 시 복원 |
| W-03 | 화면 밖으로 나가지 않도록 위치 보정 (다중 모니터·해상도 변경 대응) |
| W-04 | 마우스 hover 시에만 닫기(숨기기) 버튼과 새로고침 버튼 노출 |
| W-05 | 급식 데이터가 비어 있으면 **"급식 정보가 등록되지 않았어요"**로 알린다. NEIS는 급식이 없는 날과 학교가 아직 올리지 않은 날을 구분해 주지 않으므로 "급식이 없다"고 단정하지 않는다 |
| W-06 | 일정이 없는 날: 일정 섹션 자체를 숨김 (빈 영역 남기지 않음) |
| W-07 | 내용 길이에 따라 창 높이 자동 조절. 화면 높이의 50%를 넘으면 **창을 키우지 않고 본문을 스크롤**한다. 창 자체에 최소·최대를 걸면 레이아웃 요구 높이와 충돌해 Qt가 리사이즈를 반복하다 멈추므로, 제한은 본문 영역에만 건다 |
| W-08 | 휴업일(`SBTR_DD_SC_NM`)인 경우 일정 항목을 붉은 계열로 강조 |
| W-09 | 우클릭 시 컨텍스트 메뉴 (날짜 이동 / 새로고침 / 설정 / 숨기기 / 종료) |
| W-10 | 태스크바·Alt+Tab 목록에 나타나지 않음 (도구 창 속성) |
| W-11 | 날짜 이동 — 날짜 양옆 `‹ ›` 버튼(hover 시 노출), 마우스 휠(위=과거, 아래=미래), 우클릭 메뉴. 단 **본문이 스크롤 가능한 상태면 휠은 스크롤 전용**이다. 읽는 중에 날짜가 넘어가면 안 된다 |
| W-14 | 재료·원산지는 기본으로 접어 둔다. 포스트잇을 **클릭**하면 펼치고 다시 클릭하면 접는다. 끌어서 옮긴 경우는 클릭으로 보지 않는다 |
| W-15 | 접힘 상태를 알 수 있도록 `재료·원산지 보기 ▾` / `숨기기 ▴` 한 줄을 둔다. 보여줄 재료가 없으면 이 줄도 없다 |
| W-16 | 설정에 등록한 알레르기가 들어간 요리는 **빨갛게** 표시하고 무엇 때문인지(예: `· 우유`) 함께 적는다. 펼친 재료 문구 안의 해당 낱말도 같이 강조한다 |
| W-17 | 그림자는 `QGraphicsDropShadowEffect`가 아니라 직접 그린다. 반투명 최상위 창에 이펙트를 걸면 Windows에서 레이어드 창 갱신이 실패한다 |
| W-18 | 창은 **내용을 채운 뒤에** 띄운다. 빈 창을 먼저 띄우면 크기가 어긋나 `setGeometry` 경고가 뜨고 화면에서도 창이 한 번 커진다 |
| W-12 | 오늘이 아닌 날을 볼 때만 **[오늘]** 칩이 상시 노출된다. 돌아올 길을 항상 열어 둔다 |
| W-13 | 오늘 기준 ±2일은 날짜 옆에 `· 어제` `· 내일` 같은 상대 표기를 덧붙인다 |

### 3.2 트레이 아이콘

**항상 표시된다.** 포스트잇이 숨겨져 있어도 트레이 아이콘은 남으며, 앱의 유일한 상시 진입점이다.

```
  [트레이 아이콘] 우클릭
  ┌──────────────────────┐
  │ 미림마이스터고         │  ← 비활성 (현재 학교 표시)
  ├──────────────────────┤
  │ 포스트잇 보이기   ✓   │
  │ 지금 새로고침         │
  ├──────────────────────┤
  │ 설정...               │
  │ 학교쪽지 정보         │
  ├──────────────────────┤
  │ 종료                  │
  └──────────────────────┘
```

| ID | 내용 |
| --- | --- |
| T-01 | 앱 실행 중 항상 트레이에 아이콘 표시 |
| T-02 | 좌클릭(또는 더블클릭): 포스트잇 표시/숨김 토글 |
| T-03 | 우클릭: 위 메뉴 표시 |
| T-04 | 툴팁에 "학교쪽지 — {학교명}" 표시 |
| T-05 | 오류 상태(키 만료, 네트워크 장애)일 때 아이콘에 배지/변형 표시 |
| T-06 | 창을 닫아도 앱은 종료되지 않음. 종료는 트레이 메뉴에서만 |
| T-07 | 트레이를 지원하지 않는 환경에서는 포스트잇을 강제 표시하고 경고 |

### 3.3 설정 창

탭 3개로 구성. 첫 실행 시 자동으로 열린다.

#### 탭 1 — 인증키

```
 ┌── 설정 ─────────────────────────────────────┐
 │ [인증키] [학교] [표시]                       │
 │                                              │
 │  NEIS 인증키                                 │
 │  ┌────────────────────────────┐ ┌────────┐   │
 │  │ ●●●●●●●●●●●●●●●●●●●●●●●●●● │ │ 키 확인│   │
 │  └────────────────────────────┘ └────────┘   │
 │  ☐ 키 보기                                   │
 │                                              │
 │  ✅ 유효한 인증키입니다.                      │
 │                                              │
 │  ── 인증키가 없으신가요? ──────────────       │
 │  1. open.neis.go.kr 접속 후 회원가입         │
 │  2. 상단 [인증키 신청] 메뉴 선택             │
 │  3. 활용 목적 입력 후 신청 (즉시 발급, 무료) │
 │  4. 마이페이지에서 인증키 복사               │
 │                                              │
 │  [ 발급 페이지 열기 ↗ ]                      │
 │                                              │
 │                        [ 취소 ]  [ 저장 ]    │
 └──────────────────────────────────────────────┘
```

| ID | 내용 |
| --- | --- |
| K-01 | 인증키는 기본적으로 마스킹 표시. "키 보기" 체크 시 평문 노출 |
| K-02 | **[키 확인]** 버튼: `schoolInfo`를 `pSize=1`로 호출해 `RESULT.CODE`로 유효성 판정 |
| K-03 | 검증 결과를 인라인 상태로 표시 — 성공/실패/오류를 각각 다른 문구와 색으로 |
| K-04 | 검증 중에는 버튼 비활성화 + 스피너. UI는 절대 멈추지 않음(별도 스레드) |
| K-05 | 발급 절차 안내를 설정 창 안에서 항상 볼 수 있게 상시 노출 (접기 가능) |
| K-06 | **[발급 페이지 열기]** 버튼이 기본 브라우저로 `https://open.neis.go.kr` 오픈 |
| K-07 | 검증 실패한 키도 저장은 허용하되, 저장 시 경고 표시 |

**키 검증 결과 매핑**

| 판정 | 조건 | 사용자에게 보이는 문구 |
| --- | --- | --- |
| 성공 | `RESULT.CODE`가 정상 코드이거나 데이터 목록이 반환됨 | ✅ 유효한 인증키입니다. |
| 키 오류 | 인증키 미등록/유효하지 않음 계열 코드 | ❌ 인증키가 올바르지 않습니다. 다시 확인해 주세요. |
| 한도 초과 | 일일 트래픽 초과 계열 코드 | ⚠️ 오늘 호출 한도를 초과했습니다. 내일 다시 시도해 주세요. |
| 네트워크 | 타임아웃 / DNS / 연결 실패 | ⚠️ 서버에 연결할 수 없습니다. 네트워크를 확인해 주세요. |
| 알 수 없음 | 그 외 | ⚠️ 확인하지 못했습니다. ({코드}: {메시지}) |

> NEIS `RESULT.CODE` 실제 값은 구현 시 라이브 응답으로 검증하고 `app/neis/codes.py`에 상수로 고정한다.
> 초기 관찰 대상: `INFO-000`(정상), `INFO-200`(데이터 없음), `ERROR-290`/`INFO-300`(인증키 문제),
> `ERROR-300`(필수값 누락), `ERROR-337`(일일 트래픽 초과).

| ID | 내용 |
| --- | --- |
| S-01 | 학교명 일부만 입력해도 검색 (`schoolInfo`의 `SCHUL_NM`은 부분 일치 지원) |
| S-02 | Enter 키로도 검색 실행 |
| S-03 | 결과는 목록으로 표시. 각 행에 **학교명 / 관할 교육청 / 소재지**를 함께 보여 동명이교를 구분 |
| S-04 | 결과 100건 초과 시 상위 100건만 표시하고 "검색어를 더 자세히 입력하세요" 안내 |

**자동 시작(D-09) 세부**

| ID | 내용 |
| --- | --- |
| B-01 | 등록 위치는 OS별로 다르다 — Windows `HKCU\...\CurrentVersion\Run` 값, macOS `~/Library/LaunchAgents/{번들ID}.plist`, Linux `$XDG_CONFIG_HOME/autostart/*.desktop` |
| B-02 | 체크박스는 설정 파일이 아니라 **OS에 실제 등록된 상태**를 보여준다. 사용자가 작업 관리자에서 껐을 수 있다 |
| B-03 | 저장 시 값이 바뀌지 않았으면 OS를 건드리지 않는다. 등록된 명령이 현재 실행 파일과 다르면(설치 위치 이동) 다시 쓴다 |
| B-04 | 등록 실패는 조용히 넘기지 않고 알린다. 다만 실패한 상태를 설정에 "켜짐"으로 적지 않는다 |
| B-05 | 등록할 수 없는 환경에서는 체크박스를 비활성화하고 이유를 알린다 |
| B-06 | 개발 중 실행(패키징 전)에는 `-m app` 대신 `run.py` 절대 경로를 등록한다. 자동 시작은 작업 디렉터리를 보장하지 않는다 |

### 5.1 설정 파일

위치는 `QStandardPaths.AppConfigLocation` 기준:

| OS | 경로 |
| --- | --- |
| Windows | `%APPDATA%\SchoolNote\config.json` |
| macOS | `~/Library/Preferences/SchoolNote/config.json` |

```jsonc
{
  "version": 2,
  "school": {
    "office_code": "B10",              // ATPT_OFCDC_SC_CODE
    "office_name": "서울특별시교육청",
    "school_code": "7010084",          // SD_SCHUL_CODE
    "school_name": "미림마이스터고등학교",
    "school_kind": "고등학교"
  },
  "display": {
    "meal_types": ["lunch"],           // breakfast | lunch | dinner
    "grade_filter": null,              // null = 전체, 1~6
    "show_allergy": false,
    "show_calorie": true,
    "expand_details": false,        // 재료·원산지를 기본으로 펼칠지
    "allergy_alerts": [2, 16],      // 빨갛게 표시할 알레르기 번호
    "always_on_top": true,
    "opacity": 0.95,
    "color": "yellow",
    "start_on_boot": false,
    "show_on_start": true
  },
  "window": { "x": 1520, "y": 80, "width": 280 },
  "state": { "last_sync": "2026-07-29T09:12:03+09:00" }
}
```

> **인증키는 이 파일에 저장하지 않는다.** 5.3 참조.

**스키마 이력**

| version | 변경 |
| --- | --- |
| 1 | 최초. `show_origin`(원산지 표시 여부)이 있었다 |
| 2 | `show_origin`을 버리고 `expand_details`(처음부터 펼침)로 대체. v1은 두 값을 같은 것으로 옮겨 놓아서, 원산지를 보려고 켜 둔 사용자가 전부 펼친 채로 시작했다. v1 설정을 읽을 때 `expand_details`를 기본값으로 한 번 되돌린다 |

## 6. 외부 API 명세

### 6.1 공통

- 베이스: `https://open.neis.go.kr/hub/{서비스명}`
- 공통 파라미터: `KEY`(인증키), `Type=json`, `pIndex`(페이지, 기본 1), `pSize`(1~1000, 기본 100)
- 응답 최상위에 `RESULT`(상태) 또는 `{서비스명}` 배열이 옴 — **구조가 상황에 따라 달라지므로 방어적 파싱 필수**

### 6.2 사용 서비스

| 서비스 | 엔드포인트 | 용도 |
| --- | --- | --- |
| 학교기본정보 | `/hub/schoolInfo` | 학교 검색, 인증키 검증 |
| 급식식단정보 | `/hub/mealServiceDietInfo` | 급식 조회 |
| 학사일정 | `/hub/SchoolSchedule` | 행사·일정 조회 |

**schoolInfo** — 요청: `SCHUL_NM`(부분 일치) / 응답: `ATPT_OFCDC_SC_CODE`, `ATPT_OFCDC_SC_NM`, `SD_SCHUL_CODE`, `SCHUL_NM`, `SCHUL_KND_SC_NM`, `LCTN_SC_NM`, `ORG_RDNMA`(도로명주소)

**mealServiceDietInfo** — 요청: `ATPT_OFCDC_SC_CODE`, `SD_SCHUL_CODE`, `MLSV_YMD` 또는 `MLSV_FROM_YMD`/`MLSV_TO_YMD`, `MMEAL_SC_CODE`(1=조식, 2=중식, 3=석식) / 응답: `MMEAL_SC_NM`, `DDISH_NM`, `CAL_INFO`, `NTR_INFO`, `ORPLC_INFO`

**SchoolSchedule** — 요청: `ATPT_OFCDC_SC_CODE`, `SD_SCHUL_CODE`, `AA_YMD` 또는 `AA_FROM_YMD`/`AA_TO_YMD` / 응답: `AA_YMD`, `EVENT_NM`, `EVENT_CNTNT`, `SBTR_DD_SC_NM`(휴업일 구분), `ONE_GRADE_EVENT_YN` ~ `SIX_GRADE_EVENT_YN`

호출 예시:
```
https://open.neis.go.kr/hub/mealServiceDietInfo
  ?KEY={인증키}&Type=json&pIndex=1&pSize=10
  &ATPT_OFCDC_SC_CODE=B10&SD_SCHUL_CODE=7010084&MLSV_YMD=20260729
```

### 6.3 인증키

- 발급처: <https://open.neis.go.kr> 회원가입 → 인증키 신청 (무료·즉시 발급)
- data.go.kr의 해당 데이터셋 페이지는 안내용이며, 실제 호출 키는 NEIS 개방포털에서 발급받는다
- 일일 트래픽 한도는 기관 정책에 따르므로 **캐싱을 전제로 설계**한다 (본 앱은 학교 1곳 기준 1일 2~3회 호출)

## 7. 기술 아키텍처

### 7.1 모듈 구조

```
app/
├─ __main__.py          # 진입점, 단일 인스턴스 보장, QApplication 부트스트랩
├─ tray.py              # QSystemTrayIcon, 컨텍스트 메뉴
├─ sticky.py            # 포스트잇 위젯 (프레임리스 QWidget)
├─ settings_dialog.py   # 설정 창 (탭 3개)
├─ config.py            # 설정 로드/저장, 스키마 마이그레이션
├─ secrets_store.py     # keyring 래퍼 + 폴백
├─ autostart.py         # 부팅 시 자동 시작 등록 (레지스트리/LaunchAgent/XDG)
├─ scheduler.py         # 자정 롤오버, 절전 복귀 감지, 재시도 백오프
├─ neis/
│  ├─ client.py         # HTTP 호출, 타임아웃, 재시도
│  ├─ codes.py          # RESULT.CODE 상수 및 분류
│  ├─ models.py         # Meal, ScheduleEvent, School 데이터클래스
│  └─ parser.py         # 응답 정규화 (N-01 ~ N-07)
└─ resources/
   ├─ icons/            # 트레이 아이콘 (일반/오류, 라이트/다크)
   └─ styles/           # QSS 스타일시트
```

### 7.2 스레딩

- UI는 메인 스레드 전용
- 모든 네트워크 I/O는 `QThreadPool` + `QRunnable` 워커에서 수행
- 워커 → UI 전달은 Qt 시그널만 사용 (위젯 직접 조작 금지)
- 설정 창의 키 검증·학교 검색도 동일하게 워커 사용

### 7.3 단일 인스턴스

이미 실행 중이면 새 프로세스는 기존 인스턴스의 포스트잇을 표시시키고 즉시 종료한다.
(`QLocalServer`/`QLocalSocket` 기반)

### 7.4 플랫폼별 고려사항

| 항목 | Windows | macOS | Linux |
| --- | --- | --- | --- |

## 11. 용어

| 용어 | 설명 |
| --- | --- |
| NEIS | 교육행정정보시스템. 개방포털(open.neis.go.kr)에서 Open API 제공 |
| 시도교육청코드 | `ATPT_OFCDC_SC_CODE`. 예: 서울 `B10`, 경기 `J10` |
| 표준학교코드 | `SD_SCHUL_CODE`. 학교 고유 식별자 |
| 급식구분코드 | `MMEAL_SC_CODE`. 1=조식, 2=중식, 3=석식 |
| 휴업일 구분 | `SBTR_DD_SC_NM`. 휴업일 여부 표기 |

> 시도교육청코드는 하드코딩하지 않고 `schoolInfo` 응답에서 획득해 저장한다.
