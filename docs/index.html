FEATURES

이런 점이 좋아요

불편하지 않게, 꼭 필요한 것만

📌
포스트잇 UI
제목표시줄 없는 반투명 창. 드래그해서 원하는 곳에 두면 위치가 기억됩니다.
🔄
자동 갱신
자정이 지나면 스스로 그날 급식 정보를 가져옵니다. 손 안 대도 됩니다.
📅
날짜 탐색
마우스 휠이나 ‹ › 버튼으로 어제·내일 급식도 확인할 수 있습니다.
⚠️
알레르기 경고
내 알레르기를 등록하면 해당 음식이 빨갛게 강조 표시됩니다.
🏫
학교 검색
학교 이름 일부만 입력하면 목록에서 골라 설정할 수 있습니다.
🔒
서버 없음
앱이 NEIS API를 직접 호출합니다. 개인정보가 어디에도 전송되지 않습니다.
🌙
트레이 상주
포스트잇을 닫아도 트레이에 남습니다. 아이콘을 누르면 다시 나타납니다.
🔑
키 없이도 동작
NEIS 인증키 없이도 급식·일정 조회가 됩니다. 키를 등록하면 한도가 늘어납니다.
GET STARTED

5분 안에 시작하기

실행 파일을 받아서 바로 쓰면 됩니다

1
실행 파일 다운로드
위의 다운로드 섹션에서 운영체제에 맞는 파일을 받아 압축을 풀어두세요.
2
앱 실행 후 학교 설정
처음 실행하면 설정 창이 열립니다. 학교 탭에서 학교 이름을 검색해 선택하면 바로 급식이 표시됩니다.
3
(선택) NEIS 인증키 등록
인증키 없이도 쓸 수 있지만, 일 1000건 제한이 있습니다. open.neis.go.kr에서 무료로 즉시 발급받을 수 있습니다.
4
원하는 곳에 붙여두기
포스트잇을 드래그해서 바탕화면 한 구석에 두세요. 설정에서 자동 시작을 켜두면 컴퓨터를 켤 때마다 자동으로 뜹니다.

지금 바로 사용해보세요
