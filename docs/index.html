📌
포스트잇처럼
드래그로 원하는 곳에 붙이면 위치가 기억됩니다. 마우스를 올리면 버튼이 나타납니다.
🔑
가입·로그인 없음
인증키 없이 NEIS 공개 API를 바로 씁니다. 설치 후 학교 검색만 하면 끝입니다.
🔄
자동 갱신
자정이 넘으면 스스로 당일 급식 정보를 새로 가져옵니다.
📅
날짜 탐색
마우스 휠이나 ‹ › 버튼으로 어제·내일 급식도 미리 확인할 수 있습니다.
⚠️
알레르기 경고
내 알레르기를 등록하면 해당 음식이 빨갛게 강조 표시됩니다.
🔒
서버 없음
앱이 NEIS에 직접 연결합니다. 개인정보가 어디에도 전달되지 않습니다.
🖥️
크로스플랫폼
